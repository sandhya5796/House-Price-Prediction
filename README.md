# House Price Prediction using Linear Regression

## Project Overview
This project predicts house prices using Linear Regression based on housing features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Steps
1. Load dataset
2. Data cleaning
3. Feature selection
4. Train-test split
5. Linear Regression model training
6. Evaluation and prediction

## Results
The model predicts house prices based on input features with good accuracy.
